# Wizard Spielstand App

Mobile-optimierte GitHub-Pages/PWA-Version.

## Update auf GitHub

1. ZIP entpacken.
2. Auf GitHub im Repository **Add file → Upload files** öffnen.
3. Diese Dateien aus dem ZIP hochladen und vorhandene Dateien überschreiben:
   - `index.html`
   - `manifest.webmanifest`
   - `sw.js`
   - `icon-192.png`
   - `icon-512.png`
   - `README.md`
4. Unten auf **Commit changes** klicken.
5. Nach 1–3 Minuten die GitHub-Pages-Seite am iPhone neu öffnen.

Falls am iPhone noch die alte Ansicht kommt: Safari-Seite einmal komplett schließen und neu öffnen. Bei Homescreen-App eventuell Icon löschen und nach dem Update neu über Safari → Teilen → Zum Home-Bildschirm hinzufügen.
