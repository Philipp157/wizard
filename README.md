# Wizard Spielstand

Mobile Wizard-Spielstand-App für GitHub Pages.

## Hochladen auf GitHub Pages

1. Auf github.com anmelden.
2. Neues Repository erstellen, z. B. `wizard`.
3. Repository auf **Public** stellen.
4. Diese Dateien in das Repository hochladen:
   - `index.html`
   - `manifest.webmanifest`
   - `sw.js`
   - `icon-192.png`
   - `icon-512.png`
5. In GitHub: **Settings → Pages**.
6. Bei **Build and deployment** einstellen:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/root`
7. Speichern.
8. Nach kurzer Zeit ist die App erreichbar unter:
   `https://<dein-github-name>.github.io/wizard/`

## iPhone Nutzung

1. Link in Safari öffnen.
2. Teilen-Symbol drücken.
3. **Zum Home-Bildschirm** auswählen.
4. Danach wie eine App starten.

## Hinweis

Der Spielstand wird lokal im jeweiligen Browser gespeichert. Er ist nicht öffentlich auf GitHub sichtbar.
